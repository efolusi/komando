The komando command line puts SSH sessions, a database client, redis-cli, storage consoles, kubectl and VPNs behind one command.

It gives your AI agent the same reach without showing it a single password.

  • sshkomando exec web-1 -- uptime
  • psqlkomando db schema prod-db users
  • redis-clikomando cache get prod-redis session:42
  • aws s3 lskomando storage list backups 2026/
  • kubectlkomando cluster status prod-k8s
  • wg-quickkomando vpn up office

AI agents komando recognises by itself. For any other agent, set KOMANDO_AGENT=1.

Install komando on macOS, Linux or Windows

One line installs release v0.15.0. Then run komando version to check it. The source is on GitHub.

macOS, Linux and Windows

Open a terminal and run this line. On Windows, komando runs through WSL: open a WSL terminal and run the same line.

curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/sgnd/komando/v0.15.0/install.sh | KOMANDO_VERSION=v0.15.0 sh

Check it first. Download the script, read it, then run it. Its sha256 is 9089ae0c0fbe7689aaf327237c02267b6b7f39dd8060187f91b22f24b46fc4af.

curl --proto '=https' --tlsv1.2 -fsSLO https://raw.githubusercontent.com/sgnd/komando/v0.15.0/install.sh
shasum -a 256 install.sh
less install.sh
KOMANDO_VERSION=v0.15.0 sh install.sh

The installer checks that the release is signed with the komando project's key (the check komando update makes) and installs nothing otherwise.

With Go 1.27.4 or newer

With Go installed, this line builds komando from its source.

go install github.com/sgnd/komando/cmd/komando@latest
