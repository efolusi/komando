Panduan pengguna Komando

Belum dirilis Aplikasi Komando belum dirilis. Panduan ini menjelaskannya seperti saat nanti dirilis. Command line sudah bisa dipakai sekarang: lihat Mulai.

Cara memakai Komando, aplikasi gratis untuk Mac, iPhone, dan iPad yang menjalankan command line komando untuk Anda. Satu halaman untuk setiap hal yang Anda lakukan. Baru memakai Komando? Mulai dari Sepuluh menit pertama Anda.

Nama tombol aplikasi ditulis tebal. Perintah, alamat, dan path file ditulis mono. Label Segera menandai bagian yang belum dibuat; Yang akan datang mencantumkan semuanya.

Mulai di sini

Sepuluh menit pertama Anda Sebagian segeraInstal komando, buka Komando, tambahkan satu server, lalu buka terminal di server itu.Menambahkan server Sebagian segeraMasukkan server ke inventaris, uji, lalu impor server yang sudah Anda punya.Login dengan key atau kata sandi Sebagian segeraPilih cara Komando login ke server, percayai identitas server, dan ubah nanti.Menambahkan database, cache, atau lainnya Sebagian segeraTambahkan database, cache, storage, cluster, registry, atau message queue, lalu periksa.Home dan temuan Sebagian segeraLihat apa yang perlu ditangani dan perbaiki dengan satu tombol.Mengenal jendela aplikasi Sebagian segeraEnam tempat beserta shortcut-nya, memberi ruang, memuat ulang, tab, dan ikon menu bar.

Server

Membuka terminalDapatkan command prompt di server, bagi layarnya, dan sambungkan ulang.File dan menyalin antar-server Sebagian segeraSalin file antara Mac ini dan server.ServiceLihat service di server dan restart, hentikan, atau jalankan salah satunya.LogBaca log sistem server, log satu service, atau file log, dan ikuti secara langsung.Update Sebagian segeraLihat update yang menunggu di server, instal, dan reboot bila perlu.ContainerLihat container Docker di server beserta lognya, lalu restart atau hentikan salah satunya.JobJalankan perintah panjang yang tetap berjalan setelah Anda memutus koneksi, dan ikuti lognya.

Data dan jaringan

Database Sebagian segeraKueri database dengan aman, dan ubah data hanya bila Anda memang ingin.CacheCari key di cache seperti Redis, baca isinya, dan ubah dengan sengaja.Port forwardingJangkau database atau halaman web di server dari Mac ini lewat tunnel.VPNTambahkan VPN, nyalakan dan matikan, dan ketahui saat koneksinya putus.

Alat

KeychainBeri komando kata sandi dan key yang dibutuhkan, lalu pasang key di server.RecipeJalankan perintah tersimpan di satu server atau satu grup, dan simpan milik Anda sendiri.Agen Sebagian segeraJelaskan masalah dengan kata-kata, lalu biarkan agen menemukan dan memperbaikinya, dengan bertanya dulu.

Keamanan

Touch ID dan keamananAllow changes, target yang dilindungi, audit log, dan kunci Touch ID.Mengubah, melindungi, atau menghapus Sebagian segeraUbah server atau koneksi, lindungi, atau keluarkan dari inventaris.
