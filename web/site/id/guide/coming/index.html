Yang akan datang

Bagian Komando yang dijelaskan panduan ini tetapi belum dibuat.

Belum dirilis Aplikasi Komando belum dirilis. Panduan ini menjelaskannya seperti saat nanti dirilis. Command line sudah bisa dipakai sekarang: lihat Mulai.

Bagian Komando berikut sudah dirancang tetapi belum dibuat. Panduan menandai masing-masing dengan label Segera di tempatnya nanti. Sampai saat itu, setiap halaman menjelaskan apa yang bisa Anda lakukan sekarang.

Link unduh untuk aplikasinya

Situs ini akan menautkan ke Komando untuk Mac dan ke App Store untuk iPhone dan iPad.

Menunggu: Tempat aplikasi Mac dipublikasikan, dan halaman App Store-nya.

Di panduan: Sepuluh menit pertama Anda

Tanya setiap kali, untuk server atau koneksi

Pilihan keempat di bawah Log in with pada New Host dan Edit Host, dan pada kata sandi koneksi: tidak ada yang disimpan, dan kata sandi ditanyakan di sebuah tab setiap kali Komando terhubung.

Menunggu: komando 0.15.0, yang menambahkan mode yang bertanya saat terhubung. Sampai saat itu formulirnya menawarkan SSH Agent, Saved Key, dan Password, dan kata sandi koneksi disimpan. Formulir VPN sudah punya Ask each time sendiri.

Di panduan: Menambahkan server, Login dengan key atau kata sandi

Ubah kata sandi koneksi di lembar Edit-nya

Edit… pada database atau cache mendapat kolom kata sandi baru, seperti Edit Host…: kata sandi yang tersimpan tampil sebagai satu baris, dan kolom kosong berarti tetap memakai yang lama.

Menunggu: Lembar Edit Connection. Sampai saat itu, ganti nilainya di halaman Keychain.

Di panduan: Menambahkan database, cache, atau lainnya, Mengubah, melindungi, atau menghapus

Alat grup di Hosts

Add Hosts to Group… (centang beberapa server), Change Login for Group… (satu login untuk setiap server dalam grup, dengan uji coba dulu), dan Add to group saat Anda mengimpor.

Menunggu: Sudah dirancang, belum dibuat. Saat ini Anda mengatur grup server di Groups saat menambah atau mengeditnya.

Di panduan: Menambahkan server

Tempat Files yang baru

Files menjadi tempat tersendiri di sidebar (⌘4). Setiap sisi memilih This Mac, sebuah server, atau sebuah storage bucket; Swap menukarnya. Copy to web-1 (⌥⌘→) dan Copy to This Mac (⌥⌘←), folder utuh, seret dari Finder, klik kanan untuk Rename…, Move…, Permissions…, dan Delete…, Retry pada transfer yang gagal, Only copy changed files, dan Copy to a Group….

Menunggu: Branch Files P1 milik aplikasi, yang menjadikan Files sebuah tempat. Saat ini Files adalah tab untuk satu server.

Di panduan: File dan menyalin antar-server

Menyalin dari satu server ke server lain

Pilih server di tiap sisi Files lalu salin silang. komando belum bisa menyalin langsung antara dua server, jadi Komando mengunduh ke Mac ini, mengunggah, lalu menghapus salinan di sini, dan memberi tahu Anda dulu.

Menunggu: Tempat Files yang baru.

Di panduan: File dan menyalin antar-server

Files di iPhone dan iPad

Tombol Browse Files pada setiap server dan storage bucket di aplikasi ponsel.

Menunggu: komando: unduh ke ponsel dan unggah dari ponsel lewat key terbatas milik ponsel.

Di panduan: Mengenal jendela aplikasi, Komando di iPhone dan iPad

Recipe di iPhone dan iPad

Pilih recipe tersimpan dan jalankan di server dari ponsel. Recipe yang mengubah sesuatu lewat kartu persetujuan agen.

Menunggu: Sudah dirancang, belum dibuat.

Di panduan: Komando di iPhone dan iPad

Update keamanan di Home

Kartu di Home seperti "3 servers have security updates." dengan Review, dan satu kartu untuk server yang perlu reboot.

Menunggu: Sudah dirancang, belum dibuat. Saat ini Anda melihat update di tab Updates setiap server.

Di panduan: Home dan temuan, Update

Tab Backups milik database

Backup database, Back Up Now, dan Restore, yang selalu bertanya dulu.

Menunggu: Belum digambar.

Di panduan: Database

Mengubah storage, cluster, registry, atau queue

Tombol untuk mengunggah ke bucket, me-restart deployment, atau mengirim pesan ke queue.

Menunggu: Belum dirancang. Saat ini: ⌘K, lalu Run a Command….

Di panduan: Menambahkan database, cache, atau lainnya

Upgrade

Sinkronisasi antar perangkat, tim, AI bawaan tanpa key milik Anda sendiri, dan persetujuan dari ponsel.

Menunggu: Belum dibuat dan tidak dijual. Komando dan komando gratis, dan semua yang ada di perangkat Anda sendiri berfungsi sekarang.

Di panduan: Agen
