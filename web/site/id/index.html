Setiap jawaban komando dalam teks atau JSON

Instal komando di macOS, Linux, atau Windows

Satu baris menginstal rilis v0.17.0. Lalu jalankan komando version untuk memeriksanya. Kode sumbernya ada di GitHub.

macOS, Linux, dan Windows

Buka terminal dan jalankan baris ini. Di Windows, komando berjalan lewat WSL: buka terminal WSL dan jalankan baris yang sama.

curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/sgnd/komando/v0.17.0/install.sh | KOMANDO_VERSION=v0.17.0 sh

Periksa installer-nya dulu. Unduh skripnya, baca, lalu jalankan. sha256-nya adalah 9089ae0c0fbe7689aaf327237c02267b6b7f39dd8060187f91b22f24b46fc4af.

curl --proto '=https' --tlsv1.2 -fsSLO https://raw.githubusercontent.com/sgnd/komando/v0.17.0/install.sh
shasum -a 256 install.sh
less install.sh
KOMANDO_VERSION=v0.17.0 sh install.sh

Installer memastikan rilisnya ditandatangani dengan kunci proyek komando (pemeriksaan yang sama dengan komando update) dan tidak menginstal apa pun jika gagal.

Dengan Go 1.27.4 atau lebih baru

Kalau Go sudah terpasang, baris ini membangun komando dari kode sumbernya.

go install github.com/sgnd/komando/cmd/komando@latest
