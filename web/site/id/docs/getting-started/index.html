Mulai

komando adalah satu program yang dijalankan di terminal. Di halaman ini Anda menginstalnya, menambah satu server, memeriksa bahwa komando bisa login, melihat-lihat isi server itu, lalu menghubungkan agen AI.

Di halaman ini

  • 1. Instal komando
  • 2. Tambah server
  • 3. Periksa dan lihat-lihat
  • 4. Lindungi production
  • 5. Hubungkan agen AI
  • Langkah berikutnya

1. Instal komando

Salin baris instal dari Instal komando di halaman utama, lalu tempel ke terminal (di macOS, aplikasi Terminal). Untuk Windows dan cara instal lain, baca Instal, update, hapus.

Lalu periksa bahwa komando berjalan:

komando version

Muncul command not found? Installer menaruh komando di folder yang belum dicari oleh terminal. Jalankan baris export PATH=... yang dicetaknya, lalu tambahkan baris itu ke ~/.zshrc (macOS) atau ~/.bashrc (Linux) agar tetap berlaku.

2. Tambah server

Ketik komando host add dan jawab satu pertanyaan per baris: nama, alamat, user, port, cara komando login, dan apakah ini production. Setelah itu komando menampilkan perintah lengkapnya, jadi lain kali bisa diketik sendiri:

komando host add web1 ubuntu@203.0.113.10

Kalau ssh sudah berjalan di komputer ini, biasanya komando juga berjalan: komando memakai key yang sama dan ssh-agent yang sama. Selengkapnya tentang login ada di Server.

Sudah punya daftar server di ~/.ssh/config? Bawa semuanya sekaligus. Dry run menampilkan dulu apa yang akan ditambahkan:

komando import ssh-config --dry-run
komando import ssh-config

Sumber lain, seperti file .env, ~/.pgpass, atau PuTTY, ada di Pindah ke komando dan pindah komputer.

3. Periksa dan lihat-lihat

komando test web1      # bisakah komando login?
komando facts web1     # server apa ini, dan apa yang perlu diperhatikan?

facts melaporkan OS, CPU, memori, disk, beban, package manager, dan tool yang terinstal. Perintah ini juga menyebut apa yang perlu diperhatikan, misalnya OS yang tidak lagi mendapat update keamanan. Selengkapnya di Pemeriksaan kesehatan dan jaringan.

Jalankan satu perintah, atau buka shell di server:

komando exec web1 -- uptime
komando shell web1

Semua yang ada setelah -- adalah perintah yang berjalan di server. Menjalankan perintah juga menjelaskan tugas panjang dan perintah tersimpan.

4. Lindungi production

Tandai server production sebagai protected. Setelah itu setiap perubahan di server itu bertanya dulu kepada Anda, di terminal:

komando host edit web1 --protected

Keamanan menjelaskan apa yang dihentikan komando, dan apa yang perlu dilakukan saat komando menghentikan Anda.

5. Hubungkan agen AI

komando guide install

Perintah ini menghubungkan agen (Claude Code, Codex, Cursor, atau Gemini CLI) ke komando. Kata sandi tetap di vault komando, dan agen tidak pernah mendapatkannya dari sana. Jalankan lagi setiap kali selesai komando update. Skill agen menjelaskan apa yang dipasangnya dan apa yang tetap bertanya dulu kepada Anda.

Langkah berikutnya

  • Target: bekerja di satu server, satu grup, satu tag, atau semuanya sekaligus.
  • File: membaca, mengedit, dan menyalin file dengan aman.
  • Database dan Cache: query keduanya dari command line yang sama.
  • Glosarium: kata-kata yang dipakai komando, dalam bahasa sehari-hari.
