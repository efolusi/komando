Dokumentasi komando

Cara memakai komando, command line gratis untuk server, database, cache, queue, dan lainnya, bagi manusia dan agen AI. Satu halaman per fitur. Baru memakai komando? Mulai dari Mulai. Ingin menghubungkan agen AI? Baca Skill agen.

Perintah, flag, dan path file ditulis mono. Bantuan untuk perintah apa pun: komando <command> --help.

Mulai di sini

Mulaikomando adalah satu program yang dijalankan di terminal. Di halaman ini Anda menginstalnya, menambah satu server, memeriksa bahwa komando bisa login, melihat-lihat isi server itu, lalu menghubungkan agen AI.Instal, update, hapuskomando adalah satu file program. Halaman ini menunjukkan cara menginstalnya di macOS, Linux, dan Windows, menjaganya tetap terbaru, menyalakan tab completion, dan menghapusnya lagi.Pindah dari TermiusTermius dan komando sama-sama menyimpan daftar server dan login ke sana lewat SSH. Halaman ini menunjukkan cara membawa host ke komando, dan di mana setiap tugas sehari-hari berada setelah itu.

Yang dikelola komando

ServerTambahkan server, pilih cara komando login ke sana, dan jaga daftarnya tetap rapi.DatabaseQuery, periksa, backup, dan pulihkan database PostgreSQL, MySQL/MariaDB, SQL Server, Oracle, ClickHouse, Snowflake, BigQuery, SQLite, dan MongoDB dengan aman.CacheBaca dan ubah key di cache yang kompatibel dengan Redis (Redis, Valkey, KeyDB, Dragonfly) dan memcached dengan aman.QueueLihat dan kerjakan message queue dengan aman: Apache Kafka, dan yang berbicara dengan protokolnya (Redpanda, Amazon MSK, Confluent Cloud, Aiven), RabbitMQ, NATS dengan JetStream, Amazon SQS, dan Google Cloud Pub/Sub.Storage: bucket dan file serverTelusuri, unduh, unggah, dan bagikan file di bucket yang kompatibel dengan S3, Google Cloud Storage, Azure Blob Storage, di server WebDAV, FTPS, SFTP, dan FTP, serta di share Windows (SMB), semuanya dengan perintah yang sama.FileBaca, edit, dan salin file di server dengan aman.Cluster (Kubernetes dan Docker Swarm)Lihat dan ubah apa yang berjalan di Kubernetes dan Docker Swarm dengan satu set perintah. kubectl atau docker tidak dibutuhkan di komputer ini: komando berbicara ke cluster sendiri.Container registryLihat image apa yang disimpan sebuah registry, salin image antar-registry, dan bersihkan yang lama. Berfungsi dengan Docker Hub, GHCR, GitLab, Harbor, Amazon ECR, Azure Container Registry, Google Artifact Registry, dan registry:2 milik sendiri.VPNJangkau server dan database yang berada di balik VPN, bahkan beberapa VPN sekaligus, tanpa berpindah-pindah di antaranya.Login cloudkomando berbicara ke AWS sendiri, tanpa aws CLI: komando memakai profil di ~/.aws/config, dan seseorang memperbarui login SSO dengan satu perintah.Server privat dan tunnelJangkau server dan layanan yang tidak ada di internet, lalu buka di aplikasi di komputer ini.Server WindowsKelola server Windows di samping server Linux: jalankan PowerShell, baca dan tulis file, salin file, serta mulai dan hentikan service.TargetPilih server, conn, dan VPN yang dikerjakan sebuah perintah: satu nama, satu grup, satu tag, atau semuanya.Service, log, Docker, package, userAdministrasi server sehari-hari, dengan hasil terstruktur sebagai ganti output terminal mentah.Pemeriksaan kesehatan dan jaringanCari tahu server apa ini, apakah sehat, dan apa yang bisa dijangkaunya.

Keamanan dan rahasia

KeamananSabuk pengaman yang dipasang komando pada setiap perintah, siapa yang ditanya sebelum perintah berisiko berjalan, dan apa yang dilakukan saat sebuah sabuk menghentikan Anda. · Standar keamananSecretSimpan kata sandi, passphrase key, atau token sekali, lalu rujuk sebagai secret:NAME alih-alih mengetiknya. komando menampilkan nilai yang tersimpan hanya kepada orang yang memintanya dengan --reveal (secret show, key show), di terminal atau setelah "Allow once" di jendela komando, dan tidak pernah kepada agen AI.Standar keamananSeberapa jauh komando memenuhi standar keamanan internasional yang cocok untuk tool DevOps yang menyimpan kredensial dan dijalankan oleh agen AI. · KeamananRotasi key dan kata sandi, dan saat seseorang pergiGanti key atau kata sandi di semua tempat komando memakainya, dengan urutan yang benar, dan cabut akses saat seseorang pergi.

Referensi

Menjalankan perintahJalankan perintah dan script di satu atau banyak server, mulai tugas panjang, dan simpan perintah yang sering dipakai.Hasil dan kesalahanCara komando menjawab, arti exit code, cara memperbaiki kesalahan yang umum, dan cara melihat apa yang masih berjalan.Kode kesalahanSetiap kode kesalahan yang diberikan komando, dengan exit code-nya, contoh pesan, dan langkah berikutnya yang lazim. hint milik kesalahan itu sendiri menyebut apa yang dilakukan dalam kasus itu. Halaman ini dibuat dari kode (komando schema mencantumkan hal yang sama di error_codes). Hasil dan kesalahan menjelaskan yang paling umum. Contoh pesan adalah kata-kata komando sendiri, jadi tetap dalam bahasa Inggris.Pengaturan dan fileUbah pengaturan komando, dan lihat di mana komando menyimpan datanya serta key yang membukanya.Skill agenkomando guide install menghubungkan agen AI ke komando. Halaman ini menjelaskan apa yang dipasangnya, bagaimana komando mengenali agen, apa yang bisa dilakukan agen sendiri, dan apa yang selalu menunggu jawaban dari Anda.GlosariumKata-kata yang dipakai di dokumentasi ini, dalam bahasa sehari-hari.Pindah ke komando dan pindah komputerBawa masuk server dan database yang sudah ada, dan pindahkan semuanya ke komputer lain.
