Pindah dari Termius

Termius dan komando sama-sama menyimpan daftar server Anda dan login ke sana lewat SSH. Halaman ini menunjukkan cara membawa host Anda ke komando, dan di mana setiap tugas sehari-hari berada setelah itu.

Di halaman ini

  • Bawa host Anda
  • Kata sandi dan key
  • Tempat tugas sehari-hari
  • Yang berbeda
  • Pindah ke komputer lain

Bawa host Anda

komando tidak membaca data Termius. komando membaca file SSH config, daftar host biasa yang dipakai ssh sendiri:

  1. Taruh host Anda di ~/.ssh/config, satu blok Host untuk masing-masing, kalau belum ada di sana. Salin alamat, user, port, dan path key dari setiap host di Termius.
  2. Lihat apa yang akan ditambahkan komando, tanpa menambahkan apa pun: komando import ssh-config --dry-run
  3. Impor host itu, misalnya ke sebuah grup: komando import ssh-config --group work
  4. Periksa bahwa komando bisa login ke semuanya: komando test @work

Untuk membaca file lain, tambahkan path-nya: komando import ssh-config FILE. Baris ProxyJump ikut masuk, jadi server di balik jump host tetap punya jalannya ke sana.

Mengimpor file yang sama sekali lagi tidak mengubah apa pun, dan komando mencantumkan apa saja yang tidak bisa diimpor, beserta alasannya.

Kata sandi dan key

File SSH config tidak menyimpan kata sandi. Di terminal Anda, komando meminta kata sandi saat server membutuhkannya, sama seperti ssh. Untuk menyimpannya sekali di vault komando, agar script dan agen AI juga bisa login:

komando host edit web1 --ask-password      # disimpan sebagai secret:web1-pass

Atau beralih ke key. komando membuat key dan memasangnya di server Anda, dengan login yang sekarang dipakai server itu:

komando key gen deploy
komando key deploy deploy @work --set-default

Key yang sudah berjalan dengan ssh di komputer ini juga berjalan dengan komando. Selengkapnya di Server.

Tempat tugas sehari-hari

TugasDi komando
Buka terminal di serverkomando shell web1
Jalankan satu perintah di banyak serverkomando exec @web -- uptime
Simpan perintah dan jalankan lagikomando recipe add dan komando recipe run (Menjalankan perintah)
Salin file ke dan dari serverkomando upload, komando download, atau komando cp (File)
Salin dari satu server ke server lainkomando cp web1:/var/backups/db.sql.gz web2:/var/backups/
Forward portkomando tunnel start db1 -L 15432:localhost:5432 (Server privat dan tunnel)
Menjangkau server lewat jump hostkomando host add db1 admin@10.0.0.5 --via bastion
Simpan kata sandi dan keykomando secret dan komando key (Secret)

Kalau diketik tanpa argumen di terminal Anda, sebagian besar perintah ini menanyakan apa yang kurang, satu baris per pertanyaan.

Yang berbeda

  • Ini command line. Setiap tugas adalah perintah yang bisa Anda ketik, taruh di script, atau serahkan ke agen AI. Aplikasi Komando gratis untuk Mac, iPhone, dan iPad yang menjalankan perintah yang sama menyusul; panduan pengguna menjelaskannya.
  • Agen AI memakainya dengan aman. Kata sandi tetap di vault komando, dan agen tidak pernah melihatnya. Hubungkan agen Anda dengan komando guide install (Mulai).
  • Production bertanya dulu. Tandai server dengan komando host edit web1 --protected, dan setiap perubahan di server itu butuh persetujuan Anda (Keamanan).
  • Lebih dari server. Daftar yang sama menyimpan database, cache, queue, storage, cluster, dan VPN.
  • Catatan semua tindakan. komando audit menampilkan apa yang dilakukan, dan oleh siapa.

Pindah ke komputer lain

komando export --to komando-backup.json menyimpan server, koneksi, VPN, dan perintah tersimpan Anda, tanpa kata sandi. Di komputer lain, komando import komando komando-backup.json membawanya kembali. Detailnya ada di Pindah ke komando dan pindah komputer.
