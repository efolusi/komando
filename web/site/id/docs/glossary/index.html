Glosarium

Kata-kata yang dipakai di dokumentasi ini, dalam bahasa sehari-hari.

KataArti
Agen AI (AI agent)AI yang menjalankan tool sendiri untuk menyelesaikan tugas, seperti Claude Code, Codex, Cursor, atau Gemini CLI.
Jendela persetujuan (approval window)Jendela yang dibuka komando di layar Anda saat agen AI meminta menjalankan sesuatu yang butuh jawaban ya dari Anda. Perintah itu berjalan hanya setelah Anda klik Allow once. Lihat Keamanan.
Audit logRiwayat komando tentang setiap tindakan: siapa, apa, di mana, dan hasilnya. Lihat dengan komando audit.
Bastion / jump hostServer gerbang yang Anda lewati untuk menjangkau server privat. Di komando Anda menulisnya sebagai --via bastion.
BucketWadah mirip folder untuk file di object storage (S3, MinIO, R2).
CachePenyimpanan cepat dan sementara yang dipakai aplikasi untuk mempercepat kerja, seperti Redis atau Valkey.
CLI / terminalCommand-line interface: jendela tempat Anda mengetik perintah, bukan mengklik.
ClusterSekelompok mesin yang menjalankan container bersama, dikelola oleh Kubernetes atau Docker Swarm.
ConnKata komando untuk semua yang Anda sambungkan selain server: database, cache, queue, bucket storage, cluster, atau registry. Tambahkan dengan komando conn add.
ContainerAplikasi yang dikemas bersama semua yang dibutuhkannya, sehingga berjalan sama di mana saja (Docker).
Container imageAplikasi terkemas yang menjadi asal sebuah container, misalnya nginx:1.27.
Container registryServer yang menyimpan container image: Docker Hub, GHCR, Harbor, ECR.
DatabaseTempat aplikasi menyimpan datanya dalam tabel: PostgreSQL, MySQL, SQLite.
Dry runMenjalankan perintah dengan --dry-run: perintah menampilkan apa yang akan terjadi, tanpa mengubah apa pun.
Exit codeAngka hasil sebuah program: 0 berarti berhasil, selain itu berarti ada masalah. Lihat Hasil dan error.
Fingerprint / host keyKartu identitas server. Jika berubah, komando tidak menyambung (HOSTKEY_MISMATCH).
FlagOpsi yang ditambahkan ke perintah, seperti --yes atau --dry-run.
Grup (group)Kumpulan server dan conn bernama, dipakai sebagai target dengan @name (misalnya @web).
HostKata perintah untuk server: komando host add, komando host edit. Hasil perintah menyebut setiap target di field bernama host.
JobTugas panjang yang dibiarkan berjalan di server, dimulai dengan komando job start.
JSONTeks terstruktur yang mudah dibaca program. komando menjawab agen dan script dalam JSON.
Message queueLayanan yang meneruskan pesan dari satu aplikasi ke aplikasi lain: Kafka, RabbitMQ, NATS, Amazon SQS, Google Cloud Pub/Sub. Lihat Queue.
NamespaceBagian bernama di dalam cluster Kubernetes, untuk memisahkan aplikasi.
Object storageLayanan yang menyimpan file sebagai objek di dalam bucket, dijangkau lewat internet: S3, MinIO, R2.
PodUnit terkecil yang dijalankan Kubernetes: satu container atau lebih bersama-sama.
Protected (dilindungi)Server, conn, atau VPN yang ditandai dengan --protected, untuk production. Sebelum ada perubahan di sana, komando bertanya kepada Anda; agen AI atau script butuh --yes, yang disetujui oleh seseorang. Lihat Keamanan.
RecipePerintah siap pakai atau tersimpan, dijalankan dengan komando recipe run NAME TARGET.
SecretKata sandi, token, atau key yang disimpan di vault terenkripsi milik komando, dirujuk sebagai secret:NAME.
Selector / targetApa yang dikerjakan sebuah perintah: nama, grup (@web), tag (tag:prod), glob (web-*), atau all. Lihat Target.
ServerKomputer (sering di cloud) yang menjalankan aplikasi Anda.
ServiceProgram latar belakang, seperti nginx, yang dikelola oleh systemd (atau Windows). Dikelola dengan komando svc.
SSHCara aman untuk login dan mengendalikan server Linux dari jauh.
SSH keySepasang file yang membuktikan siapa Anda; lebih aman daripada kata sandi.
sudoMenjalankan perintah sebagai administrator (root).
Tag / labelSatu kata (prod) atau pasangan key=value (env=prod) yang Anda tempelkan ke server dan conn, supaya bisa dipilih sebagai target.
TunnelMembuat layanan jarak jauh, seperti database, tampil di komputer Anda sendiri.
VaultPenyimpanan terenkripsi milik komando untuk kata sandi dan secret lainnya.
VPNTautan jaringan privat ke jaringan perusahaan atau cloud. komando bisa menyambungkan beberapa sekaligus, dengan sendirinya, saat sebuah target membutuhkannya.
Daftar Anda (your list)Semua yang Anda tambahkan ke komando: server, conn, dan VPN. Lihat dengan komando list.
