Komando's window has a sidebar of places on the left, the place you picked in the middle, and the agent on the right when you open it. This page shows how to move around it with the mouse and the keyboard.

## The six places

The sidebar has six places: **Home**, **Hosts**, **Connections**, **Files**, **Port Forwarding** and **Recipes**. Press ⌘1 to ⌘6 to go to them. **Jobs**, **Keychain** and **Audit Log** are under **More**: press ⌥⌘1, ⌥⌘2 and ⌥⌘3.

**Files** shows this Mac beside one server or one storage connection. Open it from the sidebar, from **Files** in a server's menu, or press ⌘K and type the server's name ("Open Files on web-1"). While files are being copied, Files shows a small number in the sidebar: how many copies are running. See [Files and copying between servers](guide:files).

## Make room

- Drag the sidebar's right edge to make it wider or narrower. Double-click the edge to put it back.
- Hide the sidebar with the button beside the window buttons, with **View** › **Hide Sidebar**, or with ⌃⌘S. Show it again the same way.
- Drag the left edge of the agent the same way.
- Komando remembers these sizes, and whether the sidebar and the agent are showing, the next time you open it.

## Reload

⌘R, **Go** › **Reload** or the round arrow at the top right reads again what you are looking at: the list on a place, the lines on a Logs tab, both folders on Files.

## Tabs

- ⌃Tab goes to the next tab, and ⌃⇧Tab to the one before.
- ⌘W closes the tab in front. If a terminal in that tab is still running, Komando asks first, because closing it ends the session.

## Quit and close

If terminal sessions or file copies are still running, Komando asks before it quits: **Quit Anyway** or **Cancel**.

Closing the window does not quit. Komando stays in the menu bar, and the work goes on.

## The menu bar icon

From the icon in the menu bar you can also:

- connect a VPN that is down: the VPN's name › **Connect**. A VPN that needs a password opens Komando to ask for it;
- start a saved forward that is off: **Saved forwards** › its name › **Start Forward**, or edit it;
- stop an open forward: **Stop Forward**.

## Workspaces

To remove a saved set of tabs, press ⌘K, right-click the workspace and choose **Remove Workspace…**. It asks first. Removing a workspace closes no tab.

## On iPhone and iPad

Nothing changes there. The phone has five places: **Home**, **Targets**, **Recipes**, **Agent** and **Settings**. Files on the phone comes later. {coming:phone-files}
