Komando apps

Komando runs the komando command line for you, as a free app: Komando for Mac, and Komando for iPhone and iPad.

In testing The Komando apps are built and in testing. They have no download link and no date yet. This guide describes them. The command line works today: see Getting started.

Where to begin:

  • Your first ten minutes. Install komando, open Komando, add one server and open a terminal on it.
  • Updates. See which updates a server is waiting for, install them, and reboot when one needs it.
  • Komando on iPhone and iPad. Pair the phone with komando, see findings and fix them with Face ID.
  • What is coming. The parts of Komando this guide describes that are not built yet.

The app's own button names are in bold. Commands, addresses and file paths are in mono. A Coming pill marks a part that is not built yet; What is coming lists them all.
