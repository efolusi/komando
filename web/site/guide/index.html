Komando user guide

Not released The Komando apps are not released yet. This guide describes them as they will ship. The command line works today: see Getting started.

How to use Komando, the free app for Mac, iPhone and iPad that runs the komando command line for you. One page per thing you do. New to Komando? Start with Your first ten minutes.

The app's own button names are in bold. Commands, addresses and file paths are in mono. A Coming pill marks a part that is not built yet; What is coming lists them all.
