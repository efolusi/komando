What is coming

The parts of Komando this guide describes that are not built yet.

Not released The Komando apps are not released yet. This guide describes them as they will ship. The command line works today: see Getting started.

These parts of Komando are designed but not built yet. The guide marks each one with a Coming pill where it would be. Until then, each page says what to do today.

A download link for the apps

This site will link to Komando for Mac and to the App Store for iPhone and iPad.

Waits on: Where the Mac app is published, and the App Store listing.

In the guide: Your first ten minutes

Ask each time, for a server or connection

A fourth choice under Log in with on New Host and Edit Host, and on a connection's password: nothing is saved, and the password is asked for in a tab each time Komando connects.

Waits on: komando 0.15.0, which adds a mode that asks at connect. Until then the forms offer SSH Agent, Saved Key and Password, and a connection's password is saved. VPN forms already have their own Ask each time.

In the guide: Add a server, Log in with a key or a password

Change a connection's password in its Edit sheet

Edit… on a database or cache gets a new-password field, as Edit Host… has: the saved one shows as a line, and an empty field keeps it.

Waits on: The Edit Connection sheet. Until then, replace the value on the Keychain page.

In the guide: Add a database, cache or anything else, Edit, protect or remove

Group tools on Hosts

Add Hosts to Group… (tick several servers), Change Login for Group… (one login for every server in a group, with a practice run first), and Add to group when you import.

Waits on: Designed, not built yet. Today you set a server's groups under Groups when you add or edit it.

In the guide: Add a server

The new Files place

Files becomes its own place in the sidebar (⌘4). Each side picks This Mac, a server or a storage bucket; Swap trades them. Copy to web-1 (⌥⌘→) and Copy to This Mac (⌥⌘←), whole folders, drag in from Finder, right-click for Rename…, Move…, Permissions… and Delete…, Retry on a failed transfer, Only copy changed files, and Copy to a Group….

Waits on: The apps' Files P1 branch, which makes Files a place. Today Files is a tab for one server.

In the guide: Files and copying between servers

Copy from one server to another

Pick a server on each side of Files and copy across. komando cannot copy straight between two servers yet, so Komando downloads to this Mac, uploads, then deletes the copy here, and says so first.

Waits on: The new Files place.

In the guide: Files and copying between servers

Files on iPhone and iPad

Waits on: komando: download to the phone and upload from it through the phone's limited key.
