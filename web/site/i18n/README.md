# Indonesian site copy

Sources for the Indonesian tree of komando.efolusi.com (gap W02). The pages are built under `/id/` once the site moves to Meridian's marketing export (gap W01).

- `page-map.md`: every page, its English path and its Indonesian path.
- `home.id.md`: the Indonesian copy of the home page, section by section, in the order of `index.html`.

The guide and the docs get their Indonesian sources beside their English ones (`guide/src/*.id.md`, `docs/src/*.id.md`), built by `guide/build.py` and `scripts/docsgen`.
