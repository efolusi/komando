komando docs

How to use komando, the free command line for your servers, databases, caches, queues and more, for people and AI agents. One page per feature. New to komando? Start with Getting started.

Commands, flags and file paths are in mono. Help for any command: komando <command> --help.

Start here

Getting startedkomando is one program you run in a terminal. In this page you install it, add one server, check that komando can log in, look around on it, and connect your AI agent.Install, update, removeInstall komando on macOS, Linux or Windows, update it, tab completion, remove it.Switch from TermiusTermius and komando both keep a list of your servers and log in to them over SSH. This page shows how to bring your hosts into komando, and where each everyday task lives once they are there.

What komando manages

ServersAdd servers, log in with keys, passwords or your password manager.DatabasesQuery, back up and restore PostgreSQL and MySQL/MariaDB; query and back up SQLite; query SQL Server, Oracle, ClickHouse, Snowflake, BigQuery and MongoDB.CachesRead and change Redis, Valkey and memcached.QueuesKafka topics, RabbitMQ queues, NATS JetStream streams, Amazon SQS queues and Google Cloud Pub/Sub topics: list, peek, lag, send.Storage: buckets and file serversBrowse, download, upload and share files in S3, Google Cloud and Azure buckets, on WebDAV/FTPS/SFTP/FTP servers and Windows (SMB) shares.FilesRead, edit and copy files safely; copy whole folders.Clusters (Kubernetes and Docker Swarm)Kubernetes and Docker Swarm: status, list, logs, apply, restart, scale.Container registriesList repositories and tags, inspect and copy images, delete old ones.VPNsReach targets behind WireGuard, OpenVPN, Tailscale, AnyConnect, IPsec and other VPNs, several at once.Cloud loginsLog in to AWS SSO once; S3, SQS and ECR conns that use your AWS profile; a conn per S3 bucket.Private servers and tunnelsReach servers and services that are not on the internet.Windows serversRun PowerShell, files, copies and services on Windows servers.TargetsPick what a command works on: one name, a group, a tag, everything.Services, logs, Docker, packages, usersDay-to-day administration, security updates, restarts.Health and network checksWhat is this server, is it healthy, what can it reach, when do certificates expire.

Safety and secrets

SafetyThe seatbelts and what to do when one stops you.SecretsSave passwords and tokens once, use them as secret:NAME, read them from Vault, cloud secret managers, 1Password, Bitwarden or KeePass.Security standardsHow komando measures up to OWASP, NIST, ISO 27001 and SLSA.Rotate keys and passwords, and when someone leavesChange a key or a password everywhere, in order; when someone leaves.
