komando docs

How to use komando, the free command line for your servers, databases, caches, queues and more, for people and AI agents. One page per feature. New to komando? Start with Getting started.

Commands, flags and file paths are in mono. Help for any command: komando <command> --help. Looking for the Mac, iPhone and iPad apps? Read the user guide.

Start here

Getting startedkomando is one program you run in a terminal. In this page you install it, add one server, check that komando can log in, look around on it, and connect your AI agent.Switch from TermiusTermius and komando both keep a list of your servers and log in to them over SSH. This page shows how to bring your hosts into komando, and where each everyday task lives once they are there.
