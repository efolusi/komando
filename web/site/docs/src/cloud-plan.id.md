# Paket cloud

Command line komando gratis dan open source, dan aplikasi Komando untuk Mac, iPhone, dan iPad juga akan gratis. Halaman ini tentang paket berbayar yang menyusul nanti. Paket itu belum tersedia.

## Yang gratis sekarang

- Setiap perintah, dalam teks atau JSON, di mesin Anda sendiri.
- Tab terminal, klien database, dan port forwarding di aplikasi.
- Perbaikan sekali klik, agen, dan menu bar di aplikasi.
- Tanpa akun dan tanpa masa uji coba.

## Yang rencananya ditambahkan paket ini

- Sinkronisasi antar perangkat Anda.
- Tim.
- AI bawaan, tanpa API key sendiri.
- Menyetujui perubahan dari ponsel.

## Posisinya sekarang

Belum ada yang bisa dibeli. Harga dan cara penagihannya belum ditetapkan. Halaman ini akan mengabarkannya saat paketnya siap, beserta harganya.
